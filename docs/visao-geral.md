# Visão geral

## O jogo

MMORPG para PC, criado em grupo, com mundo aberto e foco em trazer mecânicas novas para o gênero.

## Pilares

1. **Mundo aberto:** exploração livre, regiões conectadas, PvP no mundo aberto com áreas seguras.
2. **Economia movida pelos jogadores:** profissões interdependentes, itens negociáveis (inclusive os fundidos), casa de leilão e saídas de recursos para evitar inflação.
3. **Fusão de itens:** nenhum drop é lixo. Itens são fundidos para melhorar atributos, com limites claros para manter o equilíbrio.
4. **Personalização de personagem:** raças, classes, magias (skills) e árvore de talentos.

## Plataforma

PC.

## Primeiro marco: fatia jogável

Antes de expandir, o objetivo é uma versão pequena e completa:

- [ ] Uma região do mapa
- [ ] Uma raça e uma classe
- [ ] Algumas magias e um inimigo
- [ ] Alguns jogadores conectados ao mesmo tempo, se vendo e lutando juntos
